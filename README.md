# Customer Churn Predictor

A Plotly Dash app predicting telecom customer churn probability using Logistic Regression, trained on the IBM/Kaggle Telco Customer Churn dataset (7,043 customers). Enter contract type, tenure, monthly charges, and internet service to get a live churn risk prediction.
